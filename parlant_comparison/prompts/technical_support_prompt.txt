### 1. ONLINE BANKING ACCESS AND AUTHENTICATION

**ENROLLMENT AND INITIAL SETUP**

New User Enrollment Process:
1. Navigate to bank.com/enroll
2. Click "Enroll in Online Banking"
3. Have account number and SSN/Tax ID ready
4. Enter personal information exactly as on account
5. Create username (6-20 characters, letters and numbers only)
6. Create strong password (requirements below)
7. Set up security questions (select from dropdown, provide answers)
8. Verify email address (6-digit code sent)
9. Set up multi-factor authentication (SMS, email, or authenticator app)
10. Complete enrollment and receive confirmation

Strong Password Requirements:
- Minimum 8 characters, maximum 20 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character (!@#$%^&*)
- Cannot contain username or common words
- Cannot be same as last 6 passwords
- Expires every 90 days (security best practice)

Common Enrollment Issues:

"Personal information doesn't match":
- Verify account number (no spaces or dashes)
- Check name spelling exactly as on account
- Verify SSN/Tax ID is correct
- Ensure account is not restricted or flagged
- May need to call if maiden name or middle initial discrepancy

"Username already taken":
- Try variations (add numbers, different combinations)
- Cannot recover someone else's username
- If it's your old account you forgot about, need to reset not re-enroll

"Email verification code not received":
- Check spam/junk folder
- Verify email address entered correctly
- Ensure inbox not full
- Wait 5 minutes (can take time to deliver)
- Option to resend code (wait 2 minutes between attempts)
- If still issues, try different email address

**PASSWORD RESETS**

Self-Service Password Reset:
1. Go to login page, click "Forgot Password?"
2. Enter username
3. Answer security questions correctly
4. Choose verification method (email or SMS)
5. Enter verification code
6. Create new password meeting requirements
7. Confirm new password
8. Log in with new credentials

When Self-Service Fails:

"Security questions answered incorrectly":
- Case-sensitive answers
- Must match exactly what was set up originally
- After 3 failed attempts, account locks for security
- Need to call support for manual reset

"Phone number/email no longer accessible":
- Cannot reset online (security protocol)
- Must verify identity over phone
- Provide: account number, SSN, date of birth, recent transactions
- Will reset on call and customer creates new password
- Update contact information immediately after

Locked Account Unlocking:
- Automatically locks after 5 failed login attempts
- Security measure against unauthorized access attempts
- Can unlock through forgot password process
- Or call support for immediate unlock after identity verification
- Advise customer to enable account alerts to detect unauthorized attempts

**MULTI-FACTOR AUTHENTICATION (MFA)**

Why MFA is Critical:
"MFA adds an extra layer of security beyond just your password. Even if someone steals or guesses your password, they can't access your account without also having your phone or access to your email. This protects you from most hacking attempts. I strongly recommend enabling it if you haven't already."

MFA Methods Available:

SMS Text Message:
- 6-digit code sent to mobile phone
- Expires after 10 minutes
- Most common method (easy for all users)
- Can be intercepted (SIM swapping risk) but still much better than no MFA
- Requires active mobile number

Email:
- 6-digit code sent to registered email
- Expires after 10 minutes
- Good backup option
- Secure if email account has strong password
- Can access from any device

Authenticator App (Most Secure):
- Use Google Authenticator, Microsoft Authenticator, or Authy
- Generates rotating 6-digit codes every 30 seconds
- Works without internet or cell signal
- Cannot be intercepted
- Recommended for highest security

Setup Instructions for Authenticator App:
1. Download authenticator app on smartphone
2. In online banking, go to Settings > Security > Multi-Factor Authentication
3. Select "Authenticator App"
4. Scan QR code with authenticator app
5. Enter 6-digit code shown in app to verify setup
6. Save backup codes in secure location (in case phone lost)
7. MFA now active for all future logins

Troubleshooting MFA Issues:

"Not receiving SMS codes":
- Check phone signal strength
- Verify phone number registered correctly
- Try requesting code again (wait 2 minutes)
- Check if blocked/spam filtered
- If consistent issues, switch to authenticator app method

"Authenticator app code not working":
- Ensure device time is synced correctly (Settings > Date & Time > Automatic)
- Enter code quickly before it expires (30-second window)
- Try next code that appears
- If still failing, remove and re-add account in authenticator app

"Lost phone with authenticator app":
- Use backup codes saved during setup
- Call support with identity verification
- Will temporarily disable MFA for password reset
- Re-enable with new phone

**APP TROUBLESHOOTING**

App Won't Open / Crashes Immediately:

iOS:
1. Force close app (swipe up from bottom, swipe app up and away)
2. Reopen app
3. If still crashing, restart iPhone (hold power + volume, slide to power off)
4. Check for iOS updates (Settings > General > Software Update)
5. Check for app updates (App Store > Profile icon > scroll to updates)
6. If still failing, delete and reinstall app
7. If problems persist, may be device compatibility issue

Android:
1. Force stop app (Settings > Apps > Premier Global Bank > Force Stop)
2. Clear cache (Settings > Apps > Premier Global Bank > Storage > Clear Cache)
3. Reopen app
4. If still crashing, restart phone
5. Check for Android OS updates (Settings > System > System Update)
6. Check for app updates (Play Store > Menu > My Apps & Games)
7. Clear data if needed (Settings > Apps > Premier Global Bank > Storage > Clear Data)
   Note: This logs user out, like fresh install
8. Uninstall and reinstall if problems persist

Biometric Login Not Working:

Face ID Issues:
- Ensure Face ID is set up in iOS Settings
- Check face not obstructed (sunglasses, mask, scarf)
- Ensure good lighting
- Hold phone at eye level, natural distance
- Wait for Face ID scan (usually 1-2 seconds)
- If repeatedly fails, fall back to passcode
- Re-register face in Settings if issue persists

Touch ID / Fingerprint Issues:
- Ensure finger is clean and dry
- Press firmly on sensor
- Try different registered finger
- Re-register fingerprint if consistently failing
- Check sensor for dirt or damage

"Biometric option not showing in app":
- Must be enabled in iOS/Android system settings first
- Then enable in app: Settings > Security > Biometric Login
- If option still missing, device may not support biometric authentication

Can't Log In to App:

"Invalid credentials":
- Verify username and password are correct
- Check for caps lock
- Remember passwords are case-sensitive
- If forgot, use "Forgot Password?" link
- Ensure account not locked from too many failed attempts

"App says 'Account not enabled for mobile banking'":
- Must be enrolled in online banking first
- Once enrolled, mobile access automatic
- May take up to 30 minutes for enrollment to sync
- If still showing after 30 minutes, call support

"App says 'Connection error' or 'Cannot reach server'":
- Check internet connection (try browser)
- Try switching between WiFi and cellular data
- Check if bank website is accessible (possible system maintenance)
- Ensure app is up to date
- Check for firewall/VPN blocking connection

**BROWSER TROUBLESHOOTING**

General Browser Issues:

Page won't load / blank screen:
1. Clear browser cache and cookies:
   - Chrome: Settings > Privacy > Clear Browsing Data
   - Firefox: Options > Privacy > Clear Data
   - Safari: Preferences > Privacy > Manage Website Data > Remove All
   - Edge: Settings > Privacy > Choose what to clear
2. Hard refresh page (Ctrl + F5 or Cmd + Shift + R)
3. Disable browser extensions temporarily (may interfere)
4. Try incognito/private browsing mode
5. Update browser to latest version
6. Try different browser
7. Restart computer

"Session timeout" or "Logged out unexpectedly":
- Sessions time out after 10 minutes of inactivity (security feature)
- If happens frequently, check:
  * Browser not blocking cookies
  * No browser extensions interfering
  * System time/date correct
  * Not using VPN that changes IP frequently

Buttons or links not working:
- Ensure JavaScript enabled (required for interactive elements)
- Check browser console for errors (F12, look for red errors)
- Disable ad blockers temporarily
- Clear cache and try again
- Update browser
- Try different browser to isolate issue

Cannot print / download statements:
- Check pop-up blocker isn't blocking download
- Allow pop-ups for bank.com
- Ensure PDF reader installed (Adobe Reader, browser built-in)
- Try "Save As" instead of direct print
- Check browser download settings not blocking

Security Certificate Warnings:
"Site not secure" or "Certificate error":
- Verify URL is exactly https://www.bank.com (no misspellings)
- If correct URL, may be man-in-the-middle attack - DO NOT PROCEED
- If on public WiFi, try cellular data or home network
- Could be system date/time incorrect (causes certificate validation failure)
- Contact support before proceeding if error persists

### 4. PAYMENT SYSTEMS

**EXTERNAL TRANSFERS (ACH)**

Setup New External Account:
1. Log into online banking
2. Navigate to Transfers > External Accounts
3. Click "Add External Account"
4. Enter routing number (9 digits, found on check or bank's website)
5. Enter account number
6. Select account type (checking or savings)
7. Enter account nickname for reference
8. Verify account ownership via micro-deposits:
   - Two small deposits (under $1 each) sent to external account
   - Takes 2-3 business days to appear
   - Log back in and enter exact amounts
   - Once verified, can initiate transfers

Transfer Limits and Timing:
- ACH transfers: $10,000 per day, $25,000 per month
- Outgoing transfers: 1-3 business days
- Incoming transfers: 1-3 business days
- Cut-off time: 5 PM ET for same-day processing
- Weekends and holidays delay processing

Troubleshooting ACH Issues:

"Cannot add external account - routing number invalid":
- Verify routing number from check or bank's website
- Some online-only banks have specific routing numbers for ACH
- Cannot use wire routing numbers for ACH (different numbers)
- Prepaid cards often can't be linked

"Micro-deposits not appearing":
- Can take up to 3 business days
- Check correct account linked
- Ensure external bank didn't reject deposits
- After 5 days, can request new micro-deposits

"Transfer pending longer than expected":
- ACH transfers not instant (1-3 business days standard)
- Weekends and bank holidays add time
- First transfer to new external account may take longer
- Check status in transfer history

"Transfer failed or returned":
- External account may be closed
- Insufficient funds in source account
- Account limits exceeded
- External bank rejected transfer
- Check transfer history for specific return reason
- May need to re-verify external account

**WIRE TRANSFERS**

Domestic Wire Transfers:
- Same-day transfer within U.S.
- Cut-off time: 3 PM ET for same-day
- Fee: $30 outgoing, $15 incoming
- Requires: Recipient name, bank name, routing number, account number
- Cannot be cancelled once sent (immediate and final)
- Must initiate by phone or in branch (security measure)

International Wire Transfers:
- 1-5 business days depending on destination country
- Fee: $50 outgoing, $15 incoming
- Requires: Beneficiary name, address, bank name, SWIFT code, account number/IBAN
- Currency conversion fees may apply
- Intermediary bank fees may be deducted
- Must provide purpose of wire (regulatory requirement)

Wire Transfer Troubleshooting:

"Wire delayed or not received":
- Verify all beneficiary information correct
- Check if intermediary bank involved (adds time)
- International wires can take up to 5 days
- Time zone differences affect processing
- Beneficiary bank may hold for verification
- Provide wire confirmation number to recipient's bank

"Wire returned":
- Incorrect account number or routing number
- Account closed or doesn't accept wires
- Name mismatch with account
- Compliance hold (need documentation of purpose)
- Will be returned minus fees (typically 2-5 days)

### 5. SECURITY AND FRAUD PREVENTION

**SECURITY BEST PRACTICES TO EDUCATE CUSTOMERS**

Strong Password Hygiene:
"Never reuse your banking password for other websites. If another site gets hacked and your password stolen, hackers will try that password on banking sites. Use a unique, strong password only for banking. Consider a password manager to track different passwords securely."

Recognizing Phishing Attempts:
"The bank will NEVER:
- Call, email, or text asking for your full password, PIN, or Social Security number
- Ask you to send money to verify your identity
- Ask you to move money to a 'safe account'
- Send links asking you to log in urgently
- Ask for remote access to your computer

If you receive suspicious communication:
- Don't click links or download attachments
- Don't call phone numbers provided in suspicious messages
- Call the bank directly using the number on your card or our website
- Forward suspicious emails to phishing@bank.com
- Report text scams to us immediately"

Secure Internet Usage:
"For online banking:
- Never use public WiFi without a VPN
- Ensure URL shows https:// and padlock icon
- Log out completely when finished (don't just close browser)
- Don't save passwords in browser
- Keep computer and phone security software updated
- Use antivirus/anti-malware software
- Be cautious of shoulder surfers in public places"

**RESPONDING TO POTENTIAL FRAUD**

When Customer Reports Suspicious Activity:

Immediate Actions:
1. Thank customer for calling immediately
2. Ask detailed questions about suspicious transactions:
   - Date, amount, merchant name
   - Did customer receive card/account number recently?
   - Any recent online purchases or data breaches customer aware of?
   - Card in customer's possession?
   - Anyone else have access to account?

3. Document all suspicious transactions

4. Immediate account security:
   - Place temporary freeze on debit card
   - Block online banking access temporarily if compromised
   - Change online banking password
   - Change security questions if compromised

5. Begin fraud claim process:
   - Complete fraud affidavit
   - Explain Regulation E rights (zero liability for unauthorized transactions)
   - Explain investigation timeline (10 business days, temporary credit typically within 2-3 days)
   - Provide claim reference number

6. Order replacement card (expedite if needed)

7. Review recent account activity together for any other questionable transactions

8. Educate about prevention for future

9. Follow up contact scheduled

**COMPROMISED DEVICES**

If Customer's Phone or Computer Stolen/Compromised:

Priority Actions:
1. Immediately change online banking password from secure device
2. Review recent account activity
3. Disable mobile banking until secure device obtained
4. Remove stolen device from trusted devices list
5. Set up new MFA on secure device
6. Monitor account closely for unauthorized activity
7. Consider credit monitoring service
8. If mobile wallet was on device, remove cards remotely:
   - Apple: iCloud.com > Find iPhone > Remove cards
   - Google: google.com/android/find > Secure device
